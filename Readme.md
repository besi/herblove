Herblove
========

Connect a PET bottle to a water drip adapter and keep your herbs happy.

## Features

- Control a 12V valve
- Battery powered with solar charging
- Measure temperature and humidity
- Log data onto an SD card
- Read a floating sensor
- Two buttons
- Onboard Neopixel

## Pinout

| Pin | Function    |
|-----|-------------|
| 2   | Enable 12V  |
| 10  | I2C SCL     |
| 8   | I2C SDA     |
| 1   | SPI MISO    |
| 4   | SPI MOSI    |
| 0   | SPI CLK     |
| 5   | SPI CS      |
| 6   | Buttons ADC |
| 3   | ADC Battery |
| 7   | Neopixel    |
